# Istruzioni per lavorare su BarberUp

- Leggere HANDOFF.md prima di qualsiasi intervento.
- Per richiesta esplicita del titolare, aggiornare sempre HANDOFF.md a ogni modifica al progetto, inclusi database, Auth, SMTP, template email, impostazioni, cron e deployment modificati fuori da GitHub.
- Inserire l'aggiornamento nello stesso commit delle modifiche quando possibile. Per interventi solo remoti, registrare comunque il risultato con un commit documentale su GitHub.
- Aggiornare lo stato corrente e il registro con data, modifica, verifiche e punti rimasti aperti. Distinguere verifiche reali da ipotesi o test non eseguiti.
- Il titolare vuole lavoro remoto su GitHub e Supabase, senza sviluppo locale. Usare il repository MISCIANDOSKY/BarberUp e il progetto Supabase wrpwitehcikplsauiwmg.
- Non toccare il repository staiul o il progetto MANOVELLA.
- Non committare segreti, token o dati personali dei clienti; non riportarli nell'handoff.
- Mantenere l'interfaccia e le email in italiano. Non cambiare impostazioni operative estranee alla richiesta.
- Le istruzioni esplicite successive del titolare hanno precedenza.
